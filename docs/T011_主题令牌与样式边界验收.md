日期：2026-11-26。状态：**已验收**。依据原计划T011及阶段00设计基线，复用现有shadcn-vue与外观设置，仅补实际缺口。

## 实现

共享样式入口仅导入Tailwind、动画与theme.css，移除重复默认主题和远程字体导入。theme.css作为语义颜色、字号、间距、圆角、尺寸及主题映射的唯一来源。用户端业务样式只负责布局，不再用全局button或.primary选择器覆盖组件背景、禁用与悬停状态。

| 令牌 | 基线 |
|---|---|
| 字号 | 12 / 13 / 14（正文）/ 16 / 18 / 20 / 24px；系统与中文字体栈 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 40px |
| 圆角 | 基础值0 / 8 / 12 / 16px，派生圆角按比例计算，直角不产生负值 |
| 行与控件 | 标准列表行48px，紧凑36px，行内垂直间距8/4px；默认按钮36px |
| 布局尺寸 | 页头56px、侧栏240px、目录树260px、内容边距24px；响应式归T012 |
| 浅色 | 背景#ffffff、正文#171717、默认主色#2563eb及白色按钮文字 |
| 深色 | 背景#101114、正文#f5f5f5、默认主色#60a5fa及#101114按钮文字 |

五种强调色分别提供明暗配色。选择、导航、焦点、主按钮悬停从语义颜色派生；错误、成功、遮罩和文件类型使用共享变量。破坏性按钮同样使用语义文字及悬停颜色。紧凑模式改变列表行，不压缩按钮点击区域；登录页保留显式44px控件尺寸。

主题初始化幂等，支持系统明暗变化、同源跨标签页同步与web/admin一致恢复。偏好使用cloudlane.theme；无效JSON、字段或枚举恢复默认，存储被禁用时保留当前可用外观，跨标签页更新不回写形成循环。
