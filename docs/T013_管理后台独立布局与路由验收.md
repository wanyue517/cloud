## 范围与查漏补缺

对照需求说明书（第 21.4 节前后台权限、独立布局约束）、阶段 00 设计基线（`T005` 4.3 管理后台独立应用壳与路由清单）及原计划 T013（搭建后台独立布局与路由，验收：与用户端无页面耦合），补齐以下缺口：

- **独立管理后台布局壳（`frontend/apps/admin/src/layout/AdminLayout.vue`）**：
  - 彻底将原组合页拆分，采用独立于用户端的后台双栏布局（左侧分组导航栏 + 顶部操作栏 + 主内容 `<RouterView />`）。
  - 桌面端支持导航栏折叠/展开，移动端（`<= 760px`）转为左侧抽屉与遮罩层，支持 `Esc` 或导航点击自动关闭。
  - 顶栏保留 `Cloudlane 管理后台` 主标题、当前模块面包屑、共享外观设置（`ThemeSettings`）、返回网盘链接（`/app`）与退出登录操作。
  - 严格隔离源码依赖：`apps/admin` 与 `apps/web` 无任何相互导入，仅复用 `@repo/ui` 与 `@repo/session`。
- **完整对齐 T005 4.3 路由清单（`frontend/apps/admin/src/router/index.ts` & `navigation.ts`）**：
  - 业务子路由均嵌套在 `AdminLayout` 下：
    - `/admin/`（`admin-dashboard`）：独立**仪表盘**页面（[dashboard/index.vue](file:///E:/wanyue/projects/cloud/frontend/apps/admin/src/views/dashboard/index.vue)），对接 `/v1/admin/stats`，展示用户、空间、文件与物理存储指标及后台模块入口。
    - `/admin/users`（`admin-users`）：独立**用户管理**页面（[users/index.vue](file:///E:/wanyue/projects/cloud/frontend/apps/admin/src/views/users/index.vue)），对接 `/v1/admin/users` 与 `/v1/admin/users/:id/status`，同步 URL `?page=` 分页参数与账号启停操作。
    - `/admin/messages`、`/admin/storage`、`/admin/settings/site`、`/admin/settings/auth`、`/admin/settings/files`、`/admin/tasks`、`/admin/logs`：按 T005 4.3 完整注册路由并统一渲染规划占位页（[placeholder/index.vue](file:///E:/wanyue/projects/cloud/frontend/apps/admin/src/views/placeholder/index.vue)），明确标注所属阶段（P1）与对应任务编号。
  - **权限与异常隔离**：`/admin/404` 与 `/admin/unavailable` 保持在 `AdminLayout` 之外，普通用户或未知路径进入 404 时不会暴露任何后台菜单或布局壳。
- **登录回跳白名单同步（`frontend/packages/session/navigation.ts`）**：
  - `safeReturnPath` 与已注册后台路由保持一致，允许已注册本地后台路由回跳，继续严格拒绝未注册路径、跨站地址、路径穿越与编码注入。
