## 范围与配置补齐

对照需求说明书第 26.4 节数据目录规范与原计划 T015（配置 MySQL、Redis 与本地文件目录），完成以下配置与目录对齐：

- **Docker Compose 编排完善（[compose.yaml](file:///E:/wanyue/projects/cloud/compose.yaml) & [.env.example](file:///E:/wanyue/projects/cloud/.env.example)）**：
  - `mysql` 服务显式配置 `utf8mb4`、`utf8mb4_0900_ai_ci` 与 UTC 时区（`--default-time-zone=+00:00`），并支持 `${DB_NAME}`、`${MYSQL_PORT}`、`${REDIS_PORT}`、`${API_PORT}`、`${WEB_PORT}` 端口/库名覆盖。

  - `cloud-api`（[application.yaml](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/resources/application.yaml)）显式声明 `cloud.storage.*` 与 `spring.data.redis.{host,port}` 环境变量覆盖项，默认本地目录为 `data/objects`、`data/uploads`、`data/previews`、`data/worker-tmp`。
  - `cloud-worker`（[WorkerLifecycleRunner.java](file:///E:/wanyue/projects/cloud/backend/cloud-worker/src/main/java/com/wanyue/cloud/worker/WorkerLifecycleRunner.java)）启动时自动创建并校验 `objects`、`previews`、`worker-tmp` 目录；`LocalStorage` 与 `UploadService` 启动时自动创建 `objects` 与 `uploads` 目录。
