# Cloudlane 备份恢复与演练指南（T176）

## 1. 备份范围（必须保持一致性）
1. **MySQL 关系数据库**（`cloud` 库）：保存用户、空间、文件树、版本引用、共享与策略。
2. **对象存储物理目录**（`CLOUD_STORAGE_ROOT`，默认 `data/objects`）：保存实际文件内容；若使用 S3，请启用桶版本控制与跨区域复制。
3. **关键密钥配置**（`.env` 中的 `JWT_SECRET`、`VERIFICATION_HMAC_SECRET` 及存储加密密钥）：丢失密钥将导致无法解密历史存储凭据。

## 2. 执行备份
Windows PowerShell：
```powershell
.\scripts\backup.ps1 -DbHost 127.0.0.1 -DbPort 3306 -DbName cloud -DbUser root -StorageRoot data/objects
```
备份产物会按时间戳归档至 `backups/cloudlane-<yyyyMMdd-HHmmss>/`，包含 `cloud.sql` 与 `objects/` 目录。

## 3. 恢复步骤
1. 停止应用写入（停止 `cloud-api` 与 `cloud-worker`）。
2. 恢复数据库：
   ```powershell
   mysql -h 127.0.0.1 -P 3306 -u root -p cloud < backups/cloudlane-<stamp>/cloud.sql
   ```
3. 恢复对象存储文件：
   ```powershell
   Copy-Item -Recurse -Force backups/cloudlane-<stamp>/objects/* data/objects/
   ```
4. 启动服务并登录管理后台：
   - 访问 `/admin/logs`，点击「孤儿演练扫描」核对 `orphanCount`；
   - 点击「重建全站索引」重新同步 Meilisearch 与全文索引分片。

## 4. 定期演练检查表
