# Cloudlane 移动端（H5 / PWA & Capacitor 原生 App）构建与发布指南

> 对应任务：**M044｜原生 App 打包脚本、发布文档与真机全链路验收**

---

## 一、双形态构建与区分说明

`frontend/apps/mobile`（`@cloud/mobile`）采用**一套代码、按运行时能力矩阵自动分流**策略：

| 形态 | 构建命令 | 基础路径 | 能力表现 |
|---|---|---|---|
| **Web H5 / PWA** | `pnpm build:mobile` | `/m/` | 自动隐藏所有原生专属入口（自托管地址配置、生物识别锁、相册自动备份、离线文件、文档扫描、外部应用打开），无任何无效按钮 |
| **Android / iOS 原生 App** | `CAPACITOR_BUILD=1 vite build && cap sync` | `./` | 自动启用 `mobileCapabilities.isNative = true`，完整开启自托管服务器连接、无 Cookie Refresh Token、生物识别与后台高斯模糊遮罩、相册自动备份、沙箱离线阅读、系统分享接收与文档扫描转 PDF |

---

## 二、Web H5 / PWA 生产部署

1. 使用发布脚本构建前端制品：
   ```powershell
   .\scripts\release.ps1 -Module mobile
   ```
2. 将 `release-dist/mobile` 部署至 Nginx `/usr/share/nginx/html/m`（项目根目录 `frontend/nginx.conf` 与 `frontend/Dockerfile` 已内置 `/m/` SPA 回退与静态资源缓存规则）。

## 三、Android Release APK / AAB 构建与签名

### 1. 前置环境
- JDK 17+（推荐与后端保持一致）
- Android SDK（API 34+）与 `ANDROID_HOME` 环境变量
- 已完成一次 `pnpm --filter @cloud/mobile run cap:sync`

### 2. 生成正式签名密钥（首次执行）
```bash
keytool -genkey -v -keystore cloudlane-release.jks -alias cloudlane \
  -keyalg RSA -keysize 2048 -validity 10000
```
将密钥文件妥善保存（**严禁提交至 Git 仓库**），并在 `frontend/apps/mobile/android/keystore.properties` 创建如下模板：
```properties
storeFile=../../cloudlane-release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=cloudlane
keyPassword=YOUR_KEY_PASSWORD
```
在 `frontend/apps/mobile/android/app/build.gradle` 的 `android { signingConfigs { release { ... } } }` 中读取该配置并绑定至 `buildTypes.release`。

### 3. 一键打包 Release APK
```powershell
.\scripts\release.ps1 -Module android-apk
```
产物位于 `release-dist/app-release.apk`（也可在 `frontend/apps/mobile/android` 下执行 `.\gradlew.bat bundleRelease` 生成 Google Play AAB）。

## 四、iOS IPA 构建与发布（需 macOS + Xcode 15+）

1. 在 macOS 上初始化并同步 iOS 工程：
   ```bash
   cd frontend/apps/mobile
   CAPACITOR_BUILD=1 pnpm exec vite build
   pnpm exec cap add ios   # 首次执行
   pnpm exec cap sync ios
   pnpm exec cap open ios
   ```
2. 在 Xcode 中配置：
   - **Signing & Capabilities**：绑定 Apple Developer Team 与 Bundle ID（`com.wanyue.cloudlane`）。
   - **Info.plist**：补充相机（`NSCameraUsageDescription`）、相册（`NSPhotoLibraryUsageDescription`）、麦克风（`NSMicrophoneUsageDescription`）与面容 ID（`NSFaceIDUsageDescription`）权限描述；如需局域网 HTTP 自托管服务，配置 `NSAppTransportSecurity` -> `NSAllowsArbitraryLoads`。
   - **Share Extension**（系统分享接收）：在 Xcode 新增 `Share Extension` Target 并配置共享 App Group，转发分享文件至主 App。
3. 执行 `Product -> Archive` 并导出 Ad-Hoc / TestFlight / App Store IPA。

## 五、真机全链路验收清单

- [ ] 首次启动 App 点击「配置自托管服务器地址」，输入私有 HTTP/HTTPS 域名/IP，测试连接成功并完成登录（无 Cookie `X-Refresh-Token` 轮换生效）。
- [ ] 开启「后台防偷窥高斯模糊遮罩」与「应用启动锁」，切后台任务视图无隐私泄露，生物识别失败/取消平滑降级至密码解锁。
- [ ] 配置「相册自动增量备份」目标目录与 Wi-Fi 条件，重复触发不产生重复文件（触发 M039 用户级 SHA-256 秒传）。
- [ ] 打开「云端相册」（`/photos`）浏览日期分组瀑布流，确认私密空间与隐藏文件严格不出现。
- [ ] 将普通文件「设为离线可用」，开启飞行模式后在「离线文件」成功打开阅读；私密空间文件严格禁止离线缓存。
- [ ] 从微信/相册通过系统分享选择「Cloudlane」接收文件；使用「文档扫描转 PDF」合成多页 PDF 并成功在线预览。
