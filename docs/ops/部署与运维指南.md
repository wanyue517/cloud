# Cloudlane 部署与运维指南

本文档面向全新服务器或本地环境部署 **Cloudlane 个人云端网盘系统**，覆盖软硬件要求、必填环境变量、Docker Compose 多配置启动、独立前后端构建部署、Nginx 反代调优、首次初始化及备份恢复。

---

## 1. 运行环境与硬件要求

### 1.1 软件版本要求
| 组件 | 最低/推荐版本 | 是否必需 | 说明 |
|---|---|---|---|
| **JDK** | Java 17 LTS | 必需（源码运行） | 后端 `cloud-api` / `cloud-worker` 编译运行环境 |
| **Maven** | 3.9+ | 必需（源码构建） | 多模块后端构建 |
| **Node.js / pnpm** | Node 22/24 + pnpm 10+ | 必需（前端构建） | Monorepo 用户端与管理后台构建 |
| **MySQL** | 8.0 / 8.4 LTS | **必需** | 字符集 `utf8mb4`，时区建议 UTC（Flyway 自动迁移 V1–V15） |
| **Redis** | 7.x | **必需** | 会话、验证码限频、缓存与异步协调（建议开启 AOF） |
| **Docker / Compose** | Docker 24+ / Compose v2 | 推荐 | 一键编排与按需启停可选扩展服务 |
| **Gotenberg** | `gotenberg/gotenberg:8` | 可选（`office` profile） | Word/PPT/Excel 打印预览转 PDF |
| **Meilisearch** | `getmeili/meilisearch:v1.11` | 可选（`search` profile） | 中文模糊搜索与正文倒排索引 |
| **Apache Tika** | `apache/tika:2.9.2.1-full` | 可选（`search` profile） | Office/PDF 正文文本提取 |
| **FFmpeg / FFprobe** | 5.x / 6.x | 可选 | 非 H.264/AAC 视频编码探测、转封装与转码 |

### 1.2 服务器硬件分级建议
- **基础版（个人 / 家庭，不含 Office 转换与全文索引）**：2–4 核 CPU、4–8 GB 内存、SSD 磁盘。
- **完整版（启用 Gotenberg + Meilisearch + Tika + 独立 Worker）**：8 核 CPU、16 GB 及以上内存、SSD 磁盘。

## 2. 必填环境变量与安全密钥配置

在项目根目录复制模板创建 `.env` 文件（**禁止将 `.env` 提交到 Git**）：
```bash
cp .env.example .env
```

关键必填项说明：
1. **数据库与 Redis**：
   - `DB_NAME=cloud`、`DB_USERNAME=cloud`、`DB_PASSWORD=<强密码>`、`MYSQL_ROOT_PASSWORD=<强密码>`
2. **独立安全密钥**（务必使用 32 字节随机 Base64，禁止复用）：
   - `JWT_SECRET`：签发访问令牌
   - `VERIFICATION_HMAC_SECRET`：邮箱验证码摘要签名
   - `CLOUD_STORAGE_SECRET_KEY`：AES-256-GCM 加密 S3 SecretKey / SMTP 密码 / OAuth Client Secret
   
   生成方式（PowerShell）：
   ```powershell
   $b = New-Object byte[] 32; [System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b); [Convert]::ToBase64String($b)
   ```
   生成方式（Linux/macOS）：
   ```bash
   openssl rand -base64 32
   ```
3. **本地文件目录**（宿主机运行需确保有读写权限，并与数据库同步备份）：
   - `CLOUD_STORAGE_ROOT=data/objects`（默认本地物理对象目录）
   - `CLOUD_UPLOAD_TEMP=data/uploads`（分片上传临时目录）
   - `CLOUD_PREVIEW_ROOT=data/previews`（派生预览缓存目录）
   - `CLOUD_WORKER_TMP=data/worker-tmp`（Worker 及 DB 存储物化缓存目录）
4. **SMTP 发信配置**：可在 `.env` 中配置初始值，也可登录后直接在管理后台 `/admin/settings/auth` 在线修改并加密保存。

## 3. 部署方式

### 方式 A：Docker Compose 一键部署（推荐）

1. **启动核心应用（MySQL + Redis + API + Worker + Nginx 前端）**：
   ```bash
   docker compose --profile app up -d --build
   ```
2. **按需追加可选扩展服务**：
   ```bash
   # 开启 Office 文档转 PDF 预览（Gotenberg）
   docker compose --profile app --profile office up -d

   # 开启全文检索与正文提取（Meilisearch + Apache Tika）
   docker compose --profile app --profile search up -d

   # 全部启用
   docker compose --profile app --profile office --profile search up -d --build
   ```
3. **默认访问地址**：
   - 用户端网盘：`http://<服务器IP>:8080/app`
   - 独立管理后台：`http://<服务器IP>:8080/admin/`
   - 后端健康与 OpenAPI：`http://<服务器IP>:8000/v3/api-docs`

### 方式 B：源码按模块独立构建部署（前后端解耦）

1. **使用发布脚本一键按模块打包**：
   ```powershell
   # 可选参数：all | backend | web | admin
   .\scripts\release.ps1 -Module all -DistDir release-dist
   ```
   产出物：
   - `release-dist/cloud-api.jar`、`release-dist/cloud-worker.jar`
   - `release-dist/web/`（部署至 Nginx 根目录 `/`）
   - `release-dist/admin/`（部署至 Nginx `/admin/` 目录）
2. **启动后端服务**：
   ```bash
   java -Xms512m -Xmx2g -jar release-dist/cloud-api.jar
   # 可选独立启动 Worker
   java -Xms256m -Xmx1g -jar release-dist/cloud-worker.jar
   ```
3. **配置 Nginx 反向代理**：直接参考或复用 [frontend/nginx.conf](../../frontend/nginx.conf)，核心要求：
   - `client_max_body_size 0;` 与 `proxy_request_buffering off;`（支持大文件分片上传不落盘缓冲）
   - 透传 `Range` / `If-Range` 请求头（支持视频/音频/PDF 断点续传与进度拖动）
   - 为 `/api/v1/.*/events$` 单独设置 `proxy_buffering off;`、`proxy_read_timeout 3600s;`（保障 SSE 消息与共享通知不断流）

## 4. 首次启动初始化与后台动态配置

1. **数据库自动迁移**：首次启动 `cloud-api` 时，Flyway 自动按顺序执行 `V1`–`V15` 迁移脚本，**无需手动执行建表 SQL**（请提前创建空库 `cloud`）。
2. **超级管理员初始化**：全新空库下，**第一个完成注册的用户**会通过事务锁原子性获得 `SUPER_ADMIN` 角色；后续注册用户均为普通用户。
3. **无需重启的动态配置项**（均可在 `/admin/` 实时修改并立即生效）：
   - **站点设置**（`/admin/settings/site`）：站点名称、品牌 Logo URL、全局公告。
   - **认证与邮件**（`/admin/settings/auth`）：公开注册开关、邮箱验证开关、密码登录开关、SMTP 加密凭据、第三方 OAuth2 提供商。
   - **文件与上传策略**（`/admin/settings/files`）：分片大小（MB）、单文件上限（MB）、并发上传会话数、会话有效期、默认用户配额（GB）、历史版本上限、目录最大深度、回收站保留天数、禁止上传后缀黑名单。
   - **多存储热切换**（`/admin/storage`）：在线新增 `LOCAL` / `S3` / `DB` 存储实例、连通性探针测试、一键切换默认写入实例（历史对象自动按原实例正常读取）。

## 5. 运维、监控与备份恢复

- **在线观测与自检**：访问 `/admin/logs` 查看全链路 `X-Trace-Id`、API 错误率与 P95 延迟，执行搜索索引一致性校验/一键重建，以及存储孤儿对象演练扫描与延迟回收。
- **异步死信处理**：访问 `/admin/tasks` 切换至「Worker 异步作业与死信」，排查失败原因并一键重试。
- **定期备份与恢复演练**：执行 `.\scripts\backup.ps1`，详细流程见 [备份恢复与演练指南](备份恢复与演练指南.md)。
