## 一、研发执行铁律（防上下文过长与防赶工规范）

为保证每个功能一次性实现完整、避免长会话后期草率收尾，所有任务必须严格遵守以下流程：

1. **小步闭环，禁止跳步**：每次仅推进 **1–3 个强关联任务**，严禁把跨阶段任务打包草草实现。
2. **禁止占位与假数据**：每个任务交付的功能必须真实接通后端 API、完成加载态/空态/错误态/权限态处理，**不得留存 `TODO`、不可点击的假按钮或硬编码模拟数据**。
3. **完成定义（DoD）四件套**：
   - 代码完整实现（前端/后端均遵循现有规范与 `@repo/api-client` 类型契约）；
   - 类型检查通过（`pnpm check:mobile`，涉及共享包或 Web 时同时跑 `pnpm check:web` / `pnpm check:admin`）；
   - 自动化测试通过（前端单测 / 后端集成测试 / 必要时生产构建 `pnpm build:mobile`）；
   - 同步更新 [移动端验收台账.md](移动端验收台账.md)（写明状态、验证命令与结果）并勾选本计划对应任务。
4. **跨会话无缝续做协议**：开启新会话或上下文压缩后，第一步读取 [移动端验收台账.md](移动端验收台账.md) 定位第一条 `待开始` 任务，第二步读取本文件对应任务细则，严格按验收标准继续执行。
5. **安全红线不可妥协**：私密空间未解锁严禁展示缩略图/缓存/搜索命中；隐藏项不可分享/固定/进入时光轴；共享文件夹面包屑必须截断在授权根，严禁泄露未授权父级。

## 二、阶段 M01：工程初始化、共享内核与移动设计基线（M001–M006）

**阶段目标**：在现有 Monorepo 中建立独立可开发、可构建、可部署的 `@cloud/mobile` 应用骨架，抽离前后端共享逻辑，落地移动端通用组件与 PWA/网络基础层。

    1. 创建 `frontend/apps/mobile/`（`package.json` 命名为 `@cloud/mobile`，依赖 Vue 3.5、Vue Router 5、Vite 8、Tailwind CSS v4、`@lucide/vue`、`@repo/ui`、`@repo/session`、`@repo/api-client`、`@vee-validate/zod`、`zod`）。
    2. 配置 `vite.config.ts`：`base: '/m/'`，`server.host: '127.0.0.1'`，`server.port: 3002`，`strictPort: true`，`hmr: { path: '/hmr' }`，`/api` 代理至 `API_PROXY_TARGET || http://127.0.0.1:8000`。
    3. 配置 `tsconfig.json` / `tsconfig.app.json` / `tsconfig.node.json`、`index.html`（含 `viewport-fit=cover` 与移动端元信息）、`src/main.ts`、`src/App.vue`、`src/styles/index.css`。

## 九、阶段 M08：Capacitor 原生 App 封装与原生能力（M037–M044）

**阶段目标**：基于已成熟的 `apps/mobile` 封装 Android / iOS 原生 App，补齐浏览器沙箱无法提供的重度原生能力。

- [x] **M037｜集成 Capacitor 与平台抽象层（Android / iOS 工程初始化）**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 在 `frontend/apps/mobile` 引入 `@capacitor/core`、`@capacitor/cli`、`@capacitor/android`、`@capacitor/ios`、`@capacitor/preferences`、`@capacitor/app`、`@capacitor/status-bar`、`@capacitor/network`。
    2. 建立 `src/native/` 平台抽象层（统一接口，Web H5 实现 vs Capacitor 原生实现），接入 `M008` 的无 Cookie Refresh Token 安全存储与自定义服务器地址配置页（支持自托管用户首次启动输入自己的 Cloudlane 域名/IP）。
  - **验收标准**：同一套代码同时支持 `pnpm build:mobile`（Web H5）与 `npx cap sync`（Android/iOS），零 Web 回归破坏。

- [x] **M038｜生物识别安全锁与后台防偷窥保护**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 接入原生生物识别插件（FaceID / TouchID / Android BiometricPrompt），支持将私密空间解锁与隐藏项验证绑定本地安全凭据。
    2. 支持「应用启动锁」开关与监听 App 进入后台（`appStateChange`）自动覆盖高斯模糊隐私遮罩。
  - **验收标准**：生物识别失败或取消时自动平滑降级为密码输入，不支持生物识别的设备隐藏相关开关。

- [x] **M039｜后端用户级 SHA-256 秒传去重与媒体 EXIF 时光轴接口**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 联动原计划 P2（T179–T181）：`UploadController` 初始化上传支持传入 `expectedSha256`，仅在**当前用户已有可读物理对象**作用域内命中秒传（杜绝跨用户探测泄露隐私）。
    2. `cloud-worker` 新增图片/视频 EXIF 拍摄时间与分辨率异步提取（Flyway 迁移补充媒体元数据字段），提供 `GET /api/v1/media/timeline` 按拍摄时间倒序分页接口（自动排除私密空间与隐藏项）。
  - **验收标准**：跨用户相同文件不触发越权秒传；时光轴接口严格隔离私密/隐藏与失权共享项，后端集成测试全绿。

- [x] **M040｜原生后台保活分片传输与相册自动增量备份**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 接入/实现原生后台分片上传下载能力（Android WorkManager / iOS URLSession Background），切后台或锁屏不中断传输。
    2. 实现相册自动备份设置页：选择备份目标空间/目录、选择手机本地相册、配置「仅 Wi-Fi」「仅充电时」条件、增量记录已备份媒体标识并结合 `M039` 秒传去重。
  - **验收标准**：切后台 10 分钟大文件续传成功；重复触发备份不产生重复文件。

- [x] **M041｜「云端相册」时光轴瀑布流视图**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 新增 `views/photos/index.vue`（从「首页」及底部/顶部入口进入）：按「年-月-日」分组的虚拟滚动媒体瀑布流，右侧提供时间轴快速拖拽定位条。
    2. 点击照片/视频直接进入沉浸式全屏预览，支持多选批量下载/分享/删除。
  - **验收标准**：上千张照片滚动流畅、缩略图按需加载与回收、私密与隐藏图片严格不出现。

- [x] **M042｜离线缓存与无网阅读**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 文件操作菜单新增「设为离线可用」，使用 `@capacitor/filesystem` 将文件写入应用私有沙箱并记录元数据（含 `nodeId`、`revision`、`currentVersionId`、`localPath`）。
    2. 「我的 -> 离线文件」集中管理离线副本，无网状态下可直接打开预览；联网后比对 `revision` 提示更新；支持配置缓存上限与一键清理。
    3. 严禁私密空间文件进入离线缓存。
  - **验收标准**：飞行模式下可正常打开已离线文件；删除云端或撤销共享后联网自动清理本地失效副本。

- [x] **M043｜系统级「分享到 Cloudlane」、外部应用打开与文档扫描转 PDF**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 配置 Android `ACTION_SEND / ACTION_SEND_MULTIPLE` Intent 与 iOS Share Extension：从微信、相册、浏览器点击系统分享直接唤起 Cloudlane 目录选择器并入队上传。
    2. 预览不支持格式或用户点击「用其他应用打开」时，调用原生 File Opener 唤起系统已安装 App。
    3. 集成原生文档扫描插件（自动边缘裁切、去阴影纠偏），将多页纸质文档合成为单个 PDF 直接上传至当前目录。
  - **验收标准**：从外部 App 分享单文件/多图均可完整入队上传；扫描生成的 PDF 可正常在线预览与全文检索。

- [x] **M044｜原生 App 打包脚本、发布文档与真机全链路验收**（已验收 · 2026-11-28）
  - **实现细节**：
    1. 编写 Android APK（Release 签名配置模板）与 iOS IPA 构建说明及自动化脚本（扩展 `scripts/release.ps1` 与 `docs/ops/移动端构建与发布指南.md`）。
    2. 完成 Android / iOS 真机全链路验收（含私有 HTTP/HTTPS 自托管地址连接、相册备份、后台传输、生物锁、离线阅读、分享接收），更新总验收台账。
  - **验收标准**：输出可安装的 Release 构建产物与完整自托管打包手册，台账全项验收闭环。
