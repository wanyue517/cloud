# 个人云端网盘开发计划（每任务 2 小时）

> 对应：产品 PRD V2.0 / 技术架构 V1.0。适合个人开发，采用纵向可验收任务而不是按文件机械拆分。
> **每条任务固定计划 2 小时**；2 小时是计划粒度，不意味着复杂问题一定能在 2 小时解决。超时应记录问题并拆出下一项，不牺牲测试和安全性。

**总量：186 个 2 小时任务 / 372 小时基础工作量。** 预留 25%—40% 返工、兼容性和联调缓冲，实际约 465—521 小时。

## 里程碑建议

- **M0 工程基线**：27 次 × 2h = **54h**。可以启动系统，完成最小登录闭环。
- **M1 个人网盘可用**：55 次 × 2h = **110h**。可注册、创建空间、操作文件、预览常见类型。
- **M2 完整协作与预览**：48 次 × 2h = **96h**。Office/媒体预览、共享、分享和版本可用。
- **M3 完整 Web V2**：48 次 × 2h = **96h**。搜索、私密、配置、质量保障及可部署。
- **M4 后续增强**：8 次 × 2h = **16h**。去重秒传、迁移及桌面客户端准备。

## 使用方式

1. 每次开始只选择**一条未完成任务**，完成任务、测试并提交代码；不要把跨多个模块的功能强行塞进 2 小时。
2. 任务完成定义：代码、必要测试、验收结果、Git 提交四者齐全。
3. 若阻塞超过 20 分钟，记录原因、可复现步骤和下一步，不允许通过省略权限校验或数据一致性来“赶进度”。
4. 每 5—8 次任务完成一次阶段联调。编号为推荐顺序；某些前端 UI 任务可提前并行，但数据模型和权限规则不可跳过。

## 计划外专项 / 风险登记

- **许可证核验**：ONLYOFFICE、字体和 FFmpeg 编译选项需在分发前核验实际版本的许可条款。
- **性能风险**：目录闭包表在大量节点移动时更新代价高，必须测真实数据规模；可对巨型移动采用异步任务。
- **全量全文检索**：扫描 PDF OCR、音视频语音转文字不是当前任务范围；先覆盖 TXT、MD、代码、Office、含文本层 PDF。
- **桌面和 APP**：Web V2 完成后单独估算，不把跨端同步引擎伪装成几个 2h 任务。
- **版本上限与配额**：验证旧版本清理、引用计数和共享空间归属，避免逻辑容量与物理容量混淆。
- **安全验收**：共享权限撤销、私密预览地址、公开分享链接失效必须服务端校验。
