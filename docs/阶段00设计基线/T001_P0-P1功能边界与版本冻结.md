# T001｜P0 / P1 功能边界与版本冻结

> Cloudlane 个人云端网盘 · 阶段 00 设计基线 · V1.0 · 2026-11-21  
> 来源：PRD V2.0、技术架构 V1.0、186 项两小时开发计划。  
> 目标：将「想要的产品」拆成可验收的首期闭环，避免将后续高级能力提前塞入基础开发。

## 1. 版本定义与重要说明

| 版本 | 对应任务 | 交付定义 | 边界 |
|---|---|---|---|
| **P0：个人网盘可用** | T001–T082（阶段 00–06） | 账号密码登录、个人空间、可展开目录树、文件上传下载、基础预览、最小后台鉴权与可本地部署 | 允许单用户优先，架构预留共享、版本与多存储；**不承诺共享和全文搜索已可用** |
| **P1：完整 Web V2** | T083–T178（阶段 07–14） | 共享空间/文件夹、文件分享、历史版本、Office/视频转换、全文搜索、私密空间、多登录、后台配置、部署质量 | 完成已确认的 Web V2 核心需求 |
| **P2：增强** | T179–T186（阶段 15） | 去重与秒传、历史存储迁移、高保真 Office 适配验证、桌面同步模型设计 | 不阻塞 Web V2 验收 |
| **多端专项** | 暂无正式工时 | PC 客户端、移动 APP、同步引擎 | P1 稳定后独立排期 |

> 注：项目计划中的 M0（工程基线，27 个任务）与**阶段 00（T001–T007，7 个任务）**是不同的统计口径。阶段 00 专注设计规范，不写代码。

## 2. P0 必须可用的能力

### 2.1 基础与身份
- Vue 3 + TypeScript Web 工作台、独立管理后台布局；支持本地启动和构建。
- Spring Boot 模块化单体、MySQL、Redis、Flyway；基本 API 文档与鉴权。
- 账号密码注册、登录、退出、刷新会话、最小个人资料修改。
- 第一个成功注册用户**原子性**成为超级管理员；普通用户不能访问管理 API；前端对已登录普通用户显示后台 404。
- 注册完成自动拥有「我的空间」（具体在 T029 实现）。

### 2.2 文件基础闭环
- 多个**个人空间**的创建、修改、排序、切换与删除确认。
- 多层级文件夹、直属子节点分页、目录树按需展开、面包屑、目录移动防环。
- 列表/网格视图、类型筛选、排序、多选、右键菜单、拖拽移动、快捷键、详情。
- 本地存储、文件上传/下载、多文件与文件夹上传、分片/断点续传、HTTP Range。
- 基础预览：图片、PDF、Markdown、文本/代码、原生可播放音频、不支持类型兜底。
- 操作中的权限检查、错误提示、回收站的基本逻辑删除。

### 2.3 P0 验收路径
新用户注册 → 自动创建默认空间 → 新建工作空间 → 创建 5 级目录 → 上传图片/PDF/Markdown → 在目录树定位并预览 → 重命名/移动 → 下载 → 删除到回收站 → 退出再登录仍可查看；第二个普通用户无法直接调用管理接口。

## 3. P1 正式范围（已确认，不随意删减）

| 领域 | P1 验收能力 | 不在该能力里偷换的概念 |
|---|---|---|
| Office 与多媒体 | Word/PPT 只读转换预览、Excel 表格模式、视频播放/必要转码、压缩包结构预览 | 不等于在线 Office 协同编辑或视频剪辑 |
| 共享空间 | 所有者邀请成员；角色权限；个人/共享空间在左侧混排 | 不等于复制整个目录树 |
| 共享文件夹 | 原目录保留、虚拟共享入口、共享中心聚合、可固定快捷访问 | 不等于将共享文件夹迁到接收者空间 |
| 分享链接 | 分享文件/文件夹；提取码、失效时间、权限和撤销 | 不等于受邀用户获得空间成员身份 |
| 文件版本 | 替换生成新版本；预览/恢复；用户上限受系统上限约束 | 重命名或移动默认不生成内容版本 |
| 搜索 | 元数据 + 可提取文本全文；分类、高亮、摘要、权限过滤 | 扫描 PDF OCR、音视频识别非必需 |
| 隐私 | 普通隐藏项、私密空间二次验证、未经解锁不暴露元数据/预览 | 「隐藏」不等于「加密」 |
| 快捷功能 | 收藏、快捷访问、批量重命名、10 秒撤销、快捷键 | 不建设通用用户操作历史界面 |
| 管理后台 | 系统消息、用户管理、存储配置、注册及登录设置、版本上限、基础审计 | 管理员身份不代表可绕过私密空间验证 |
| 存储 | Local/S3/Database 并存；切默认仅影响新上传 | 不自动迁移历史物理对象 |

P1 的第三方登录、短信验证依赖外部供应商凭据；开发验收可使用模拟服务，真实运营上线须通过供应商联调。

## 4. P2 / 候选，不计入 P0/P1 完成定义
- 同一用户安全范围内内容去重与秒传。
- 历史文件跨存储实例迁移、回滚和异常恢复。
- 高保真 Office 可插拔引擎验证。
- 更高级索引一致性巡检。
- 桌面客户端同步状态机设计。
- **智能文件整理：仅为二期候选备忘，不列入已经确认的开发承诺。**
- OCR、音视频转写、在线协同编辑、真正零知识加密、移动与桌面客户端单独立项。

## 5. 不可退让的跨版本技术约束
1. 文件逻辑节点、文件内容版本、物理 Blob 对象及具体存储实例分离。
2. 所有文件相关 API 必须在服务端完成所有权、空间范围与当前授权检查。
3. 文件名和目录路径变化不应强制移动物理对象。
4. 上传完成与文件元数据提交具备幂等/异常清理设计。
5. 预览缓存、全文索引、缩略图属于可以重建的派生数据。
6. ID 对前端使用字符串；日期标准化传输；错误码统一。
7. 私密资源在未解锁时不得被搜索、下载、预览或通过缓存泄露。
8. 阶段 00 即冻结上述边界，即使具体功能延至 P1。

## 6. 范围变更管理

新增或变更需求必须记录：`编号 / 描述 / 影响版本 / 影响模块 / 验收变化 / 决策人 / 日期`。

默认处理规则：影响数据模型与安全边界的变更先评审；纯 UI 体验优化可进入当前阶段待办；改变 P0 闭环或 P1 交付的需求需要重新评估工时。
