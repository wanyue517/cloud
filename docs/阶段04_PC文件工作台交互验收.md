# 阶段 04：PC 文件工作台交互验收（T041–T055）

## 查漏补缺与实现清单

对照 [T006_文件树与文件工作台交互规范.md](file:///E:/wanyue/projects/cloud/docs/阶段00设计基线/T006_文件树与文件工作台交互规范.md) 及需求说明书第 4.5–4.6 节，补齐阶段 04 全部核心交互缺口：

- **T041（空间导航列表与切换）**：空间导航列表新增个人/共享类型角标（`个人` / `共享`），切换空间自动重置筛选与路径上下文。
- **T042–T043（目录树懒加载、加载更多、扁平化与虚拟列表）**：
  - 新增纯函数模块 [tree.ts](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/lib/tree.ts)，实现 `flattenVisibleTree`（可见节点扁平化，含加载态/重试态/加载更多行）与 `computeVirtualWindow`（O(1) 视窗切片计算，支持十万级可见节点无卡顿）。
  - 重构 [FolderTree.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/components/drive/FolderTree.vue) 为单层虚拟化目录树：仅点击展开箭头（`hasChildren === true` 时显示）才懒加载直属子目录且不改变右侧目录，支持超过 200 项时的「加载更多」，切换空间丢弃晚到响应。
- **T044–T045（当前目录列表与列表/网格视图切换）**：支持名称/大小/修改时间/类型展示、列表与网格自由切换并持久化偏好。
- **T046（面包屑跳转与长路径折叠）**：新增 `partitionBreadcrumbs`，超过 3 层祖先时自动将中间层折叠进可点击的 `...` 下拉菜单，支持逐级跳转与 `Esc` 关闭。
- **T047–T048（文件类型自动统计标签与组合筛选）**：
  - 后端 `GET /api/v1/spaces/{space}/nodes` 新增 `category` 参数，支持与 `query`、`sort`、`hidden` 组合筛选，不改变目录树位置。
  - 前端接入 `GET /api/v1/spaces/{space}/stats` 渲染文件类型自动统计标签栏：仅显示当前目录真实存在的文件分类，独立展示文件夹数量与文件总数，支持一键切换与清除筛选。
- **T049–T051（排序、多选工具栏、右键菜单）**：服务端名称/时间/大小排序、Ctrl/Shift/全选多选与批量工具栏、shadcn ContextMenu 文件/目录差异右键菜单均已完备。
- **T052（行内新建文件夹与行内重命名）**：
  - 点击「新建文件夹」直接在列表顶部插入占位行并自动聚焦全选，Enter 提交 / Esc 取消，创建后自动选中。
  - F2 或右键/工具栏「重命名」在当前行内就地编辑，通过 `mainFilenameRange` 自动选中主文件名（不含扩展名），Enter 提交 / Esc 取消，409 冲突保留输入供重试。
- **T053（拖拽移动与目标高亮）**：列表与目录树均支持拖拽源半透明（`.is-dragging`）与合法目标文件夹高亮虚线框（`.is-drop-target`），禁止拖入自身。
- **T054–T055（快捷键作用域与文件详情侧栏）**：快捷键作用域自动避开输入框、行内编辑与所有弹窗；右侧文件详情侧栏支持展开/收起且窄屏自动隐藏。
