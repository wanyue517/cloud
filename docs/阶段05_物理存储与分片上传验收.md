  - `PUT /api/v1/uploads/{id}/chunks/{index}` 支持可选 `sha256` 校验，落盘时同步计算比对，不匹配返回 400 且立即删除临时文件，重复分片幂等；
  - `GET /api/v1/uploads/{id}` 同时返回 `received` 与 `missing` 缺失分片索引列表；
  - `POST /api/v1/uploads/{id}/complete` 支持可选 `expectedSha256`，合并写入后严格校验，不一致立即回滚并清理物理对象（返回 409），绝不发布损坏内容；
  - 过期临时分片清理任务 `cleanExpired()` 已补齐真实 MySQL 集成测试验证（清理分片文件并流转状态至 `EXPIRED`）。
