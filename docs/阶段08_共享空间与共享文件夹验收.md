## 实现清单

对照开发计划阶段 08（T097–T110），完成多人协作共享空间、任意文件夹定向共享、闭包祖先权限继承与实时权限变更通知：

- **T097（共享与邀请数据表）**：
  - 复用 V3 `space_member` 表，新增 Flyway 迁移 [V8__sharing_and_invitations.sql](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/resources/db/migration/V8__sharing_and_invitations.sql) 创建 `resource_share`（记录权限来源 `source_type`、授权人、过期与撤销时间）与 `share_invitation`（完整邀请状态机 `PENDING | ACCEPTED | REJECTED | CANCELLED | EXPIRED`）。
- **T098–T100（共享空间转换、成员邀请生命周期、角色修改与移除）**：
  - 新增 [ShareService.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/java/com/wanyue/cloud/modules/drive/share/ShareService.java) 与 [ShareController.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/java/com/wanyue/cloud/modules/drive/share/ShareController.java)：支持 `POST /api/v1/spaces/{space}/convert-shared`（保留全部原文件并补齐 `OWNER` 成员记录）、支持按邮箱/用户 ID 邀请、接受/拒绝/取消邀请、修改角色与移除成员（递增 `space.access_version` 即时生效）。
- **T101–T102（共享空间成员管理弹窗与混排导航角色标识）**：
  - 新增 [SpaceMembersDialog.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/components/drive/SpaceMembersDialog.vue) 展示成员角色、待处理邀请及转换共享空间入口；
  - [DriveService.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/java/com/wanyue/cloud/modules/drive/DriveService.java) `spaces()` 返回个人空间与受邀共享空间同层混排及有效角色，[drive/index.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/views/drive/index.vue) 侧边栏展示「共享 · 角色」标识。
- **T103–T108（任意文件夹共享、祖先授权继承、虚拟根面包屑、共享中心与全链路鉴权）**：
  - `DriveService.resolveNodeAccess()` 基于 `file_node_closure` 闭包表解析最近祖先 `resource_share` 授权，自动作用于 `list`、`stats`、`content`、`readTextChunk`、`versions`、`folder`、`upload` 及全部预览接口，无法绕过前端调用；
  - `DriveService.ancestorsForUser()` 将共享文件夹成员的面包屑祖先链严格截断在共享根 `sharedRootId`，绝不暴露未授权父级目录；
  - 新增 [FolderShareDialog.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/components/drive/FolderShareDialog.vue) 与 [SharedCenterPanel.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/components/drive/SharedCenterPanel.vue)（`/app/shared`），集中提供「与我共享」、「我发起的共享」及「收到的邀请」。
- **T109（实时权限变化通知）**：
  - 新增 [ShareEventHub.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/java/com/wanyue/cloud/modules/drive/share/ShareEventHub.java) 与 `GET /api/v1/shares/events`（SSE），成员角色变更、移除、邀请到达或文件夹共享撤销时即时向受影响用户推送 `access-changed` 事件。
- **T110（共享越权与继承集成测试）**：
  - 新增 [ShareIntegrationTest.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/test/java/com/wanyue/cloud/modules/drive/share/ShareIntegrationTest.java)，真实 MySQL 验证个人转共享保留原件、邀请前后隔离、`VIEWER` 写 403 / 升 `EDITOR` 可写 / 移除立即 404，以及深层文件夹共享子树继承、祖先链截断在共享根、猜父目录/兄弟目录 ID 返回 404 及撤销即时失效。
