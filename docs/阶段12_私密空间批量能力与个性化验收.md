  - 新增 Flyway 迁移 [V12__private_space_batch_recent.sql](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/resources/db/migration/V12__private_space_batch_recent.sql) 创建 `private_space_session`、`user_recent_access` 与 `batch_job`；

  - [PersonalAndBatchService.java](file:///E:/wanyue/projects/cloud/backend/cloud-api/src/main/java/com/wanyue/cloud/modules/drive/personal/PersonalAndBatchService.java) 实现 `POST /api/v1/spaces/{space}/private/unlock`（校验密码 + 可配 `idleMinutes` 1–120）与 `POST .../lock`；全文搜索与最近使用天然过滤 `PRIVATE` 空间，彻底阻断泄露。
- **T146–T147（普通文件/文件夹隐藏与安全限制）**：
  - `PUT /api/v1/spaces/{space}/nodes/{id}/hidden` 隐藏时自动清除收藏、快捷访问、公开分享链接、文件夹共享及搜索索引；前后端均阻止对隐藏项发起分享或固定快捷访问；用户端通过密码验证弹窗控制显示隐藏项图标按钮。
- **T148–T149（批量移动/复制/删除队列与批量 ZIP 打包下载）**：
  - `POST /api/v1/spaces/{space}/batch/execute` 逐项执行并返回明确成功/失败明细（支持 `PARTIAL` 部分成功状态）；
  - `POST /api/v1/spaces/{space}/batch/zip` 与 `GET /api/v1/batch/jobs/{jobId}/download` 实现带 500 MB 上限保护的 ZIP 打包下载，前端多选操作栏已接入「打包下载」按钮。
- **T150–T152（用户设置持久化、最近使用入口与快捷键收尾）**：
  - `GET/PUT /api/v1/me/preferences` 对接 `sys_user_setting` 表持久化主题、密度、视图、排序与默认空间；
  - `POST /api/v1/spaces/{space}/nodes/{id}/access` 与 `GET /api/v1/recent` + [RecentPanel.vue](file:///E:/wanyue/projects/cloud/frontend/apps/web/src/components/drive/RecentPanel.vue)（`/app/recent`）实现最近使用快速返回；
  - 全部快捷键（`Ctrl+K`、`Ctrl+F`、`Ctrl+A`、`F2`、`Delete`、`Enter`、`Esc`）严格避开输入框与所有弹窗。
