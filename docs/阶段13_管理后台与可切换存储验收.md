## 1. 数据库与迁移

- 新增 Flyway 迁移脚本 `backend/cloud-api/src/main/resources/db/migration/V13__admin_settings_and_storage_providers.sql`：
  - 扩展 `storage_profile` 表支持 `endpoint`、`bucket`、`region`、`access_key`、`secret_cipher`（密文存储）、`max_file_bytes`；
  - 新增 `blob_db_content` 表支持数据库小文件存储适配器；
  - 新增 `sys_oauth_provider` 表（预置 `github`、`oidc` 扩展项，支持按提供商动态配置）；
  - 预置 `sys_policy` 站点设置（`site_name` / `site_logo_url` / `site_announcement`）、注册登录策略（`auth_allow_register` / `auth_require_email_verify` / `auth_allow_password_login`）与 SMTP 加密凭据键。

## 2. 后端实现要点

- **加密凭据封装**：`SecretCipher` 采用 AES-256-GCM 加解密（输出带 `enc:v1:` 前缀），所有 S3 SecretKey、SMTP 密码、OAuth Client Secret 均密文落库，查询接口仅返回布尔标记 `hasSecret` / `hasSmtpPassword`，绝不明文回显。
- **可切换存储适配器**：
  - `S3StorageProvider` 实现 `StorageProvider` 接口及 AWS SigV4 签名连接测试（`HEAD /{bucket}` 探测）；
  - `DatabaseStorageProvider` 实现 `StorageProvider` 接口（`put`/`get`/`getRange`/`exists`/`delete`/`stat`），内置单文件上限校验（默认 4 MB，超限抛出 `413` 业务异常）；
  - `AdminController` 支持 `LOCAL | S3 | DB` 三种 `StorageProfile` 创建、在线连通性探测与默认写入实例切换（`PUT /api/v1/admin/storage-profiles/{id}/default`）。
- **站点、认证、SMTP 与 OAuth 配置**：
  - `AdminController` 提供 `GET/PUT /api/v1/admin/settings/site`、`GET/PUT /api/v1/admin/settings/auth`、`PUT /api/v1/admin/oauth-providers/{code}`；
  - `PublicSiteController` 提供匿名可访问的 `GET /api/v1/public/site-config`（已在 `SecurityConfig` 放行），供用户端登录页/全局读取站点名称、Logo 与公告。
- **已有后台模块整合验收**：
  - 仪表盘统计（T153：`/api/v1/admin/stats`）、用户列表与状态启停及会话失效（T154：`/api/v1/admin/users`）、系统消息全员/定向发布（T158：`/api/v1/admin/messages`）、文件版本与上传策略上限配置（T163：`/api/v1/admin/settings/files`）全部联调贯通。
