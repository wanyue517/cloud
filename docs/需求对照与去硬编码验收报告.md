## 二、两轮去硬编码专项整改汇总

| 原硬编码项 | 整改后动态配置入口 | 生效方式 |
|---|---|---|
| `UploadService` 写死 `CHUNK_SIZE=4MB`、`active>=20`、`1 DAY` | `/admin/settings/files` → `sys_policy` | 实时热生效，且单次会话锁定创建时分片大小 |
| `DriveService` 写死单文件 `10GB`、目录深度 `256`、配额 YAML、回收站 `30天`、无后缀黑名单 | `/admin/settings/files` → `SystemPolicyService` | 实时热生效（3 秒缓存，保存即刻失效） |
| `DriveService.upload/content` 写死 `storage_profile_id=1` 与 `LocalStorage` | `/admin/storage` 切换默认实例 → `StorageRouterService` | 新上传路由至当前默认实例（LOCAL/DB/S3），历史文件按原实例读取 |
| `AuthServiceImpl` 未校验后台注册/登录开关与登录失败锁定 | `/admin/settings/auth` → `SystemPolicyService` | 立即拦截/放行，连续失败自动锁定并在成功后清零 |
| 登录/注册/忘记密码/管理后台顶栏写死 `"Cloudlane"` | `/admin/settings/site` → `/api/v1/public/site-config` | 全站动态渲染站点名、Logo、全局公告与注册开关 |
| 忘记密码页为空壳占位、个人中心缺少修改密码与容量进度 | `forgot-password/index.vue` + `UserCenterPanel.vue` | 全流程闭环上线 |
